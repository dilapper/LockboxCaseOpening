# LockboxCaseOpening

Opening a lockbox plays a CS:GO-style case opening animation that lands on the best item inside.

Works for: Ornate Bronze, Heavy Bronze, Iron, Strong Iron, Steel, Reinforced Steel, Mithril, Thorium and Eternium Lockboxes (English client).

Install: copy the `LockboxCaseOpening` folder into `Interface/AddOns`.

Commands: `/lockcase test`, `/lockcase on`, `/lockcase off`. Click the overlay to skip.
